## 2026-08-25 — Stateful analysis graph spec + ADR 0005

Spec written: `.scratch/stateful-agent-graph/issues/01-stateful-analysis-graph.md` (ready-for-agent). No code yet.

Key decisions:
- Redesign around a persisted conversation thread whose durable centre is a typed, patchable analysis spec. The model proposes a spec patch; deterministic code resolves, validates against the closed catalogs, compiles tasks, and dispatches to a workflow subgraph. Confirmed as the canonical representation of the current quantitative question.
- Flexibility comes from spec dimensions (companies × metrics × periods × operations), not model autonomy. New metric = catalog entry; new comparison = spec operation; new capability = subgraph. No new intents.
- One new public seam: thread id + message + runtime → conversation turn. `run_turn` becomes a compatibility wrapper over an ephemeral thread so gold and per-intent tests stay green, unchanged, for the whole migration. `Runtime`, ports, and the presentation mapping are untouched.
- Trust boundary unchanged: SEC XBRL facts, `Decimal` formulas, snapshot-derived constituents, CIK identity inside tools, numeral lock. Exploratory lane is labelled, cited, read-only, and cannot emit structured rows.
- Clarify becomes a resumable interrupt holding a pending analysis. ADR 0004's one-shot rejection of a pending plan is superseded; its phrase table and candidate-set rule survive.
