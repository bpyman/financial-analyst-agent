## 2026-08-25 — Stateful analysis graph spec + ADR 0005

Spec written: `.scratch/stateful-agent-graph/issues/01-stateful-analysis-graph.md` (ready-for-agent). No code yet.

Key decisions:
- Redesign around a persisted conversation thread whose durable centre is a typed, patchable analysis spec. The model proposes a spec patch; deterministic code resolves, validates against the closed catalogs, compiles tasks, and dispatches to a workflow subgraph.
